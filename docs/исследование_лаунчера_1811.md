## 1. Про Rust

### Что это значит

Rust: язык программирования, на котором пишут быстрые и надёжные программы (части Windows, Firefox, Discord,
Cloudflare). Главное его свойство: компилятор не даёт сделать целый класс ошибок с памятью, из-за которых программы
на C/C++ падают или взламываются. Программа на Rust получается одним небольшим `.exe`, без «движка» внутри.

**Лаунчер COLDZ уже на Rust.** Он сделан на Tauri 2: это набор для окон, где

- вся работа (поиск FiveM, запуск, проверка связи, ник, маршруты, туннель входа, правка hosts, обновление) написана
  на **Rust**: `src-tauri/src/*.rs`, около 5 200 строк, 10 файлов;
- окно (кнопки, новости, 4 языка) нарисовано как веб-страница (`ui/`: HTML, CSS, JavaScript), а показывает её
  **WebView2**: встроенный в Windows 10/11 «движок» браузера Edge. Своего браузера в установщике нет.

Поэтому «перенести на Rust» не нужно: перенос уже сделан с первой версии (0.1.0). Если кто-то советует «переписать
на Rust», он, скорее всего, видел лаунчеры на Electron или C# и не знал, на чём наш.

### Чем отличается от других способов

| Способ | Пример | Размер установщика | Память в работе | Что внутри |
|---|---|---|---|---|
| **Tauri 2 (наш)** | COLDZ Launcher | **2,4 МБ** (0.3.5) | обычно 40-80 МБ | Rust + WebView2 из Windows |
| Electron | Discord, VS Code, многие лаунчеры серверов | 120-200 МБ | 150-400 МБ | JavaScript + целый Chromium в каждой программе |
| C# / .NET (WPF, WinForms) | старые лаунчеры RP-серверов | 1-80 МБ (зависит, вшит ли .NET) | 50-150 МБ | нужен .NET на ПК или вшитый .NET |
| C++ (Qt, свой) | Rockstar Games Launcher | 50+ МБ | разное | быстро, но легко сделать падающий код |

Цифры по Electron и Tauri из сравнений 2026 года (источники в конце, порядок величин, не точные замеры); наш размер:
`release\0.3.5\COLDZ-Launcher_0.3.5_x64-setup.exe` = 2 460 221 байт.

Что даёт Rust именно нам:

- маленький установщик и быстрый запуск (игрок с медленным интернетом скачивает 2,4 МБ, а не 150);
- шифрование и туннель входа (`tunnel.rs`) написаны на rustls: та же библиотека, что у обновлений, без OpenSSL;
- ошибки «упал без причины» почти исключены: в Rust нет «висящих» указателей;
- обновления подписаны своим ключом (minisign): подменить обновление нельзя без нашего секретного ключа.

Минусы Tauri, которые надо помнить:

- окно зависит от WebView2 в Windows. На Windows 11 он есть всегда, на старых Windows 10 установщик сам его докачает
  (`webviewInstallMode: downloadBootstrapper`). Если у игрока Microsoft недоступен, установка может зависнуть
  (раздел 3, пункт «Установщик»);
- антивирусы чаще настороженно смотрят на новые маленькие неподписанные `.exe` (раздел 2.6, подпись кода).

### Что можно улучшить в текущей архитектуре

| Что | Зачем | Трудозатраты |
|---|---|---|
| Разбить `lib.rs` (1 435 строк) на части: `status.rs`, `news.rs`, `update.rs`, `play.rs` | легче править и проверять, меньше риск сломать соседнее | 0,5 дня, без изменений для игрока |
| Один общий «клиент HTTP» с одинаковыми таймаутами и User-Agent для новостей, статуса, проверки связи | сейчас таймауты разбросаны по файлам (4 с, 5 с, 3 с, 6 с, 8 с) | 0,5 дня |
| Запасные адреса для `news.json` и обновлений (GitHub + coldz.vip) | если GitHub медленный или недоступен у провайдера, лаунчер остаётся без адреса сервера и без обновлений | 1 день (раздел 3) |
| Сборка на GitHub Actions (сейчас только на ПК) | повторяемая сборка, проверка тестов на каждом коммите | 1 день; ключ обновлений туда не класть, подписывать на ПК |
| Закрепить версии Tauri и плагинов (`tauri = "2"` → точная версия в `Cargo.lock`, уже есть) и раз в месяц `cargo update` с тестами | чтобы внезапное обновление библиотеки не сломало сборку перед выпуском | 1 час в месяц |
| `cargo audit` в проверке перед выпуском | предупреждает об известных дырах в библиотеках | 1 час один раз |

Ничего из этого не срочно: архитектура здоровая.

## 2. Блокировки в России

### 2.1. Что режут сейчас (ноябрь 2026)

Что известно по нашим замерам и открытым данным:

1. **Вход Rockstar** (`scui.rockstargames.com`, `*.ros.rockstargames.com`, `signin.`, `socialclub.`): у домашних
   провайдеров РФ не отвечает, а с дата-центровых узлов в Москве отвечает (наш замер 18.11, README 7г). Игрок видит
   «Failed to connect to authentication services». С января 2026 эти имена стоят в списках программ, которые
   используют игроки из РФ (источник в приватном файле).
2. **Cfx.re** (`lambda.fivem.net`, `policy-live.fivem.net`, `cfx-content.akamaized.net`): с российских узлов
   18.11 отвечали (адреса Akamai). Но на форуме Cfx.re в 2026 игроки из РФ пишут про вылеты «Lost connection to
   authentication service» каждые 3-10 минут игры и подозревают адрес «пульса» Cfx.re (`cnl…`). Модератор ответил,
   что блокирует не FiveM; причина в теме не найдена. У нас имя `cnl-hb-live.fivem.net` есть в списке hosts, но **его
   нет в проверке связи** (раздел 2.3, пункт 3).
3. **Новое с 5-6.11.2026: заморозка целых сетей зарубежных хостингов.** Исследование на Habr (435 точек у 154
   хостеров, домашний и мобильный интернет): к сетям Hetzner, OVH, DigitalOcean, Vultr, Scaleway, M247, GTHost,
   HostPapa, Clouvider, Glesys и ещё нескольким соединение «замерзает» после **~25 TCP-пакетов** (около 33 КБ) на
   домашнем интернете и **~8 пакетов** на мобильном (Билайн, МТС). Соединение не рвётся, а висит до таймаута. Считается
   на каждое соединение отдельно. Режется только TCP, UDP (например WireGuard) не трогают. Решает **сеть (AS)**, а не
   бренд хостера: тот же хостер в своей сети проходит, а в сети OVH замерзает. Это продолжение того, что Cloudflare
   описал в июне 2025 (первые 16 КБ).
4. С 2024 года основной способ блокировок в РФ по данным OONI: вмешательство в TLS (обрыв или подвисание сразу
   после первого пакета с именем сайта). С 2025-2026 в ряде регионов вводятся «белые списки» (по данным Recorded
   Future, к апрелю 2026 минимум в 74 регионах во время отключений мобильного интернета).

### 2.2. Наш подход (0.4.0): оценка

Как устроено (README 7г): лаунчер записывает адреса входа Rockstar в `hosts` → они ведут на `127.0.0.1:443` → лаунчер
пересылает каждое соединение внутри шифрованного соединения к нашему релею (сертификат закреплён по SHA-256, имени
снаружи нет) → релей читает имя из рукопожатия FiveM без расшифровки и соединяется с настоящим Rockstar.

**Что сделано хорошо:**

- шифрование FiveM ↔ Rockstar сквозное: ни лаунчер, ни релей не видят пароль и данные игрока. Это главное для
  правил Rockstar/Cfx.re и для доверия игроков;
- релей пропускает только короткий список имён (Rockstar, Cfx.re), это не общий прокси;
- лаунчер пересылает только имена, которые сам записал в hosts;
- блок в hosts между метками, убирается при выходе и подбирается после вылета;
- игровой трафик идёт напрямую на российский сервер, через релей только вход (сотни КБ);
- «Играть» не блокируется никогда, есть «Всё равно играть».

**Риски и что с ними делать:**

| Риск | Насколько вероятно | Что делать |
|---|---|---|
| Сеть релея попадёт в «замораживаемые» (2.1, п. 3): страница входа Rockstar весит сотни КБ, каждое соединение больше 25 пакетов, вход будет висеть | средне, список растёт | проверка релея с загрузкой ≥64 КБ (2.3, п. 1); релеи только в разных сетях; перед покупкой нового релея смотреть AS по ipinfo.io и сверять со свежим списком |
| Сейчас проверка релея ждёт один ответ (403 от Rockstar, 1-2 КБ). Такая проверка **проходит и при заморозке**: игрок нажмёт «Включить», а вход повиснет | высокая, если сеть заморозят | то же: читать через туннель ≥64 КБ (например, страницу `scui.rockstargames.com`), как `netcheck.rs` уже делает для манифеста Cfx.re |
| Одно соединение без имени (SNI) на порт 8443 к зарубежному IP с самоподписанным сертификатом выглядит необычно. Если начнут резать «TLS без имени» или «нестандартный порт», туннель не поднимется | низко-средне | держать запасной порт 443 на релее (добавить в `tunnels[]` вторую строку `ip:443`); лаунчер уже пробует релеи по списку |
| Rockstar видит много входов с одного IP (релея) из другой страны: может просить код из почты на каждом входе («бесконечный код подтверждения», такие темы есть на форуме Cfx.re) или ограничить частоту | средне при росте онлайна | 2-3 релея в разных странах, `limit_conn` на релее; в журнале считать ответы 429; в карточке одна строка «Rockstar может прислать код на почту, это нормально» |
| FiveM или античит могут проверять файл hosts на записи с именами Cfx.re/Rockstar | неизвестно | **проверить до выпуска** на чистом ПК: вход, подключение, 30 минут игры с блоком в hosts. Если ругается: убрать группу `cfx` из hosts, оставить только Rockstar |
| Антивирусы (Defender, Kaspersky, Dr.Web) реагируют на правку hosts («HostsFileHijack» у Defender) | средне | подпись кода (2.6); в тексте карточки сказать, что антивирус может спросить; не трогать чужие строки hosts (уже так) |
| Запрос Windows «Неизвестный издатель» дважды (включить и выключить) пугает новичков | высоко | подпись кода (2.6); второй запрос при выходе можно не показывать, если оставить блок до следующего запуска (минус: без лаунчера вход Rockstar у игрока не работает). Лучше оставить как есть, но по выключению писать одну понятную строку |
| Закон РФ: популяризация способов обхода блокировок запрещена с 1.03.2024, реклама штрафуется с 1.09.2025 | для текстов | тексты уже нейтральные («резервный маршрут входа»); этот документ и README в открытом репо: не писать инструкций, только наше устройство (рекомендация: перенести `news.json` и обновления на coldz.vip, а репозиторий сделать закрытым, раздел 3) |

**Итог:** подход верный и лучше большинства альтернатив (ниже). Главное доработать проверку релея (п. 1 ниже) и
до выпуска проверить у 2-3 игроков из РФ на разных провайдерах.

### 2.3. Что доработать в нашем подходе (по порядку важности)

1. **Проверка релея загрузкой, а не одним ответом.** `tunnel.rs probe`: через туннель скачать ≥64 КБ с
   `scui.rockstargames.com` (страница входа) и засечь, дошли ли байты за 8 с. Мало байт и тишина = «маршрут не
   отвечает», кнопку не предлагать, взять следующий релей. 0,5 дня + тест с поддельным релеем, который «замерзает»
   после 25 пакетов.
2. **Проверка входа при запуске и одно подтверждение (вариант «г» из задачи).** Уже почти так: проверка при запуске
   тихая. Сделать: если вход не отвечает, а релей проверен загрузкой, сразу под «Играть» одна строка «Вход в FiveM
   недоступен у провайдера» и кнопка «Включить резервный маршрут входа»; по «Играть» тот же запрос. Включать **без**
   нажатия нельзя: нужен запрос Windows, его должен видеть и подтвердить игрок. Запоминать выбор («включать сам при
   запуске») в `settings.json`: тогда со второго раза один запрос Windows при запуске и всё. 1 день.
3. **Добавить «пульс» Cfx.re в проверку.** Найти в исходниках FiveM (`CnlEndpoint.h`) и строках установленного
   FiveM точное имя адреса «пульса» (`cnl-hb-live.fivem.net` или `cnl.cfx-services.net`), добавить в `SERVICES`
   и в группу `cfx` для проверки. Так поймаем вылеты «Lost connection to authentication service» через 3-10 минут.
   0,5 дня.
4. **Если начнут резать сами релеи (вариант «д»).** Уже можно менять список релеев через `news.json` без выпуска.
   Добавить:
   - 3-4 релея **в разных сетях и странах** (Польша, Казахстан, + например Армения, Финляндия или Турция), перед
     покупкой проверить AS;
   - `news.json` должен скачиваться, даже если GitHub медленный: второй адрес `https://coldz.vip/launcher/news.json`
     (сайт в РФ, его не режут), лаунчер берёт первый ответивший; подпись `news.json` своим ключом (тем же minisign,
     что у обновлений, но **другим ключом**), чтобы подменённый список релеев не приняли;
   - «домен с несколькими A-записями» (например `relay.coldz.vip` → 3 адреса): удобно, но DNS у провайдера тоже могут
     подменить; лучше список IP прямо в подписанном `news.json`, а домен только как запасной путь.
   1-1,5 дня.
5. **Журнал для разбора.** В `net-check.log` писать по туннелю: сколько байт прошло и через сколько мс встало, номер
   AS релея. Тогда по журналу игрока сразу видно «замерзание» сети. 2 часа.
6. **Порт 443 на релее как второй вариант** (строка `ip:443` в `tunnels[]`, если на релее 443 свободен). 2 часа на

### 2.4. Альтернативы и почему они хуже

**(а) Свой «десинк» пакетов, как у известных программ на драйвере WinDivert.** Работает так: лаунчер ставит драйвер
перехвата пакетов и «путает» систему фильтрации у провайдера (дробит первый пакет, шлёт поддельные). Минусы:
- нужен драйвер ядра Windows и права администратора при каждом запуске; драйвер WinDivert многие антивирусы
  помечают как опасный («HackTool», «RiskWare»): лаунчер начнут удалять у игроков;
- не помогает против заморозки сетей по IP (2.1, п. 3) и против «белых списков»: там имя не важно;
- подбирать настройки надо под каждого провайдера, они ломаются при каждом обновлении фильтров;
- юридически это уже прямо «средство обхода» в смысле закона, а не маршрут через наш сервер. Распространять его
  нельзя (правило 15.11).
Вывод: не делать.

**(б) Шифрованный DNS (DoH) и скрытие имени сайта (ECH).** DoH прячет, какой адрес спросил игрок, ECH прячет имя в
рукопожатии. Минусы: имена Rockstar и так узнаются без DNS (по IP Akamai/Rockstar), FiveM сам не умеет ECH, а Rockstar
и Akamai ECH не включили; при заморозке по IP и белых списках не помогает совсем. Лаунчеру DoH нужен только для
своих запросов (новости, статус), и то не обязательно. Вывод: не поможет.

**(в) Свой «ускоритель» на WireGuard только для адресов Rockstar.** Технически надёжно (UDP сейчас не режут), но это
по сути VPN: нужен драйвер сетевого адаптера (wintun), а распространение такого средства игрокам из РФ подпадает под
запрет. Слово «VPN» Александр разрешил только как совет в карточке, не как наш продукт. Вывод: нельзя.

**(г) Проверка при запуске и включение одним подтверждением.** Делать (2.3, п. 2).

**(д) Ротация релеев.** Делать (2.3, п. 4).

**(е) Подпись кода.** Делать, но с оговоркой о стране (2.6).

**(ж) Перенести вход в сам лаунчер (окно входа Rockstar в лаунчере, а FiveM получает готовый билет).** Нельзя: это
вмешательство во вход и античит FiveM, запрещено правилами лаунчера (README «Что можно и чего нельзя»).

### 2.6. Подпись кода: что нужно от Александра

Зачем: запрос Windows («Разрешить этому приложению вносить изменения?») сейчас пишет «Неизвестный издатель» жёлтым.
С подписью там будет «Проверенный издатель: <имя>», а SmartScreen и антивирусы реже ругаются.

**Важно (данные Microsoft, обновлено 10.11.2026):**
- Azure Artifact Signing (бывший Trusted Signing), ~9,99 $/мес, доступен **частным лицам только из США и Канады**,
  организациям из США, Канады, ЕС и Великобритании. Если у Александра нет организации или гражданства/адреса в этих
  странах, этот путь **не подойдёт**.
- С 2024 года даже дорогой EV-сертификат **не убирает** предупреждение SmartScreen сразу: «доверие» копится от выпуска к
  выпуску с одной подписью. То есть подпись уберёт «Неизвестный издатель» в запросе администратора сразу, а синее окно
  SmartScreen при скачивании уйдёт через несколько выпусков.
- Обычный сертификат (OV) от центров DigiCert, Sectigo, GlobalSign и др.: 150-300 $/год, по всему миру, ключ на
  аппаратном токене или в облаке. Для лиц и компаний из РФ многие центры сейчас не выдают; надо спрашивать конкретный
  центр.
- Бесплатно для открытых проектов: SignPath Foundation (подпись OV-уровня через их сборку). Требования: открытая
  лицензия кода, сборка на их системе. Лаунчер сейчас без открытой лицензии кода, и туда пришлось бы отдать сборку.

**Пошагово (если подходит Azure):**
1. Александр решает, на кого подпись: частное лицо (США/Канада) или организация (США/Канада/ЕС/Великобритания).
2. Аккаунт Azure с картой (оплата 9,99 $/мес), создать ресурс «Artifact Signing», пройти проверку личности
   (документы, несколько рабочих дней). Это делает только Александр сам: документы и оплату Claude не вводит.
3. Получить «профиль сертификата», выдать доступ приложению для подписи (ключ доступа хранить как ключ обновлений, не в git).
4. Мы вписываем команду подписи в `scripts/sign.ps1` (`COLDZ_SIGN_COMMAND`, README раздел 6 уже готов к этому),
   выпуск подписывается автоматически.
5. Проверка: свойства `.exe` → «Цифровые подписи», запрос администратора на чистом ПК.

**Если Azure не подходит:** OV-сертификат у центра, который выдаёт в стране Александра (или через организацию в ЕС);
шаги те же, только токен. Решение и оплата за Александром. До подписи всё работает, только с «Неизвестный издатель».
