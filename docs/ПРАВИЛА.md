# Правила для следующего Claude: лаунчер COLDZ

Подробная инструкция — `README.md` (1 подготовка ПК, 2 сборка, 3–4а адрес, настройки, новости, ник, 5 выпуск,
6 подпись Windows, 7 ошибка FiveM «LinkProtocolIPC»). Здесь — правила, грабли и порядок, чтобы не повторять ошибок.
Тема в репозитории сервера: `winter-server/docs/правила/лаунчер.md` и `ник.md`.

## Правила

- Лаунчер — оболочка над настоящим FiveM (решение Александра 28.10): FiveM не скачиваем и не раздаём, файлы FiveM и игры
  не меняем, вход и античит не обходим. Обязательные строки лицензии FiveM (почта, фраза про Rockstar) не убирать.
- Новая версия игрокам — только после «да» Александра. Публикацию (push, релиз GitHub) защита сеанса может пропустить
  только по его словам в этой сессии; пересказ «да» из другой сессии для загрузки файлов в релиз не годится.
- Секретный ключ обновлений `C:\Users\Aaenl\.coldz-launcher-keys\updater.key` — никогда в git, в чат, в вывод, в копии.
  Открытый ключ в `src-tauri/tauri.conf.json → plugins.updater.pubkey` не менять никогда: установленные лаунчеры
  перестанут обновляться.
- Тексты для игроков — на 4 языках (RU основной, EN, ES, PT-BR), без длинных тире (правило Александра), по-простому.
- Новости — только для игроков, админские пункты не пишем (Александр 13.11).

## Выпуск по шагам

1. Своя ветка в отдельной папке: `git worktree add <папка> -b <ветка> main` (основную папку правит главная сессия —
   `news/news.json`). `npm install` там правит `package-lock.json` — откатить.
2. `npm test` → `npm run set-version -- X.Y.Z` → коммит «X.Y.Z: …».
3. Проверочная сборка без ключа: `$env:COLDZ_UPDATER_KEY = 'C:\nonexistent\updater.key'; npm run build`.
4. После «да»: в основной папке `git merge --ff-only <ветка>`, `npm run release -- -Notes "…"`.
5. `python scripts/verify-update.py X.Y.Z` — подпись верна открытым ключом, `latest.json` указывает на `vX.Y.Z`.
6. `git tag -a vX.Y.Z -m "…" <коммит>`, `git push origin main`, `git push origin vX.Y.Z`.
7. Релиз: `https://github.com/Poopseeque/coldz-launcher/releases/new?tag=vX.Y.Z&title=COLDZ+Launcher+X.Y.Z` в Chrome
   Александра (вход Poopseeque): описание, три файла из `release\X.Y.Z\` загрузкой файлов, «Latest», «Publish release».
8. `python scripts/verify-update.py --url` — то, что получают игроки: версия, установщик, подпись.
9. Строка в новость (`news/news.json`, 4 языка), коммит, push.

## Грабли

- «FiveM не найден» при установленном FiveM (14.11, 0.3.1 искал только ссылку `fivem://` и `%LOCALAPPDATA%\FiveM`): с 0.3.2
  поиск в `src-tauri/src/fivem.rs` (вручную, реестр, процесс, папки, ярлыки), журнал игрока
  `%APPDATA%\com.coldz.launcher\fivem-search.log`. Новый источник — в `Sources` и тест в `fivem.rs`.
- Кнопки под «Играть» должны влезать в одну строку на окне по умолчанию 1120×680, иначе вторая строка уходит под значки
  соцсетей: проверять `?fivem=0` на всех 4 языках (ES и PT — короткие подписи «Elegir FiveM.exe», «Escolher FiveM.exe»).
- FiveM требует родителя-оболочку — запуск только через `explorer.exe "fivem://connect/…"`; FiveM.exe с параметрами нельзя.
- Ник FiveM снаружи не выставить (`nickOverride` в меню FiveM главнее `cl_nickname`), параметры ссылки до сервера не
  доходят — ник уходит серверу `POST /z_menu/nick` (`src-tauri/src/nick.rs`).
- Повторный запуск FiveM — ошибки «LinkProtocolIPC … master is already initialized» / «no master process»:
  `src-tauri/src/running.rs` (0.3.1) не запускает второй раз. Помощники FiveM — файлы без `.exe` (`FiveM_DumpServer`…).
- `news/news.json` = `json.dumps(indent=2, ensure_ascii=False)`; править скриптом, проверять JSON; GitHub кэширует до ~5 мин.
- Python: `-I` игнорирует `PYTHONIOENCODING` (кириллица в cp1252 падает); в heredoc `\f` в пути становится символом —
  тексты с путями писать файлом.
- Chrome в фоне не снимает скриншоты — смотреть страницу через `find`/`read_page`.

## Проверка

- `npm test`: ник (правила как у сервера, ответы сервера, HTTP к поддельному серверу), процессы FiveM и закрытие
  пустышки, адреса, новости.
- Вид: `python -m http.server 8767` из корня → `http://127.0.0.1:8767/ui/index.html?fivem=0|address=0|nick=down|run=open|starting|stuck&close=fail`.
- «Указать FiveM.exe вручную» в окне: `?fivem=0&pick=ok` (нашёл) и `?fivem=0&pick=wrong` (выбран не FiveM.exe).
