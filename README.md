# Лаунчер COLDZ

Лаунчер для игроков сервера COLDZ на Windows. Он:

- проверяет, установлен ли FiveM; если нет — ведёт на официальную страницу загрузки `https://fivem.net/` (сам FiveM не скачивает и в установщик не входит) и сам замечает, когда FiveM появился;
- по кнопке **«Играть»** запускает настоящий клиент FiveM с подключением `fivem://connect/<адрес>`;
- даёт поставить **ник**, который будет на сервере (поле «Ник» над «Играть», раздел 4а): менять можно когда угодно, пусто — ник из FiveM;
- показывает статус сервера: онлайн или нет, игроков из 48, пинг (обновляется каждые 20 секунд), адрес сервера с кнопкой «Копировать» (для F8 → `connect <адрес>`);
- показывает новости и правила из файла `news.json` в интернете (без интернета — последние сохранённые); оттуда же может взять адрес сервера — менять адрес можно без новой версии лаунчера (раздел 3);
- ссылки на ВКонтакте, YouTube, Discord, Facebook EN/PT, TikTok (пустые не показываются);
- выглядит как экран загрузки сервера (`z_loadscreen`): чёрный фон, тонкий COLDZ с кровью, тёмно-красные акценты, та же вводная фраза и те же правила;
- окно можно растягивать и разворачивать на весь экран, в узком окне всё встаёт в одну колонку;
- языки RU (основной), EN, ES, PT-BR — выбирается сам по языку Windows, можно переключить вверху;
- сам обновляется: при запуске проверяет новую версию на GitHub и ставит её по кнопке «Обновить».

Внизу окна лаунчера и на странице лицензии в установщике есть обязательные по лицензии FiveM (п. 2.3) строки: почта владельца и фраза
`COLDZ IS NOT APPROVED, SPONSORED, OR ENDORSED BY ROCKSTAR GAMES.`

Сделан на **Tauri 2** (Rust + встроенный в Windows браузер WebView2): установщик **~2,5 МБ**, программа после установки ~5 МБ. Память: сам лаунчер ~35 МБ, вместе со встроенным браузером Windows ~200 МБ (как одна вкладка Edge). Процессор: 0% в свёрнутом виде и пока окно не активно (например, во время игры) — анимации останавливаются.

## Что можно и чего нельзя (правила FiveM)

Лицензия FiveM (Creator PLA от 10.09.2026) отдельно про лаунчеры ничего не говорит. Официального ответа Cfx.re на этот вопрос тоже нет (вопрос на форуме от 15.09.2026 остался без ответа). Поэтому лаунчер сделан максимально безопасно:

| Можно (так и сделано) | Нельзя |
|---|---|
| Запускать **настоящий** FiveM, установленный игроком, с адресом сервера | Своя сеть / синхронизация в обход FiveM (как RAGE:MP) — закроют |
| Читать открытые адреса сервера `/info.json`, `/players.json`, `/dynamic.json` | Класть FiveM в установщик или раздавать его файлы (п. 2.2 — права распространять нет) |
| Новости, ссылки на соцсети | Менять файлы FiveM или игры, внедрять код, обходить вход или античит |
| Название и логотип COLDZ | Писать «GTA», «Rockstar», использовать их логотипы в названии и оформлении (п. 2.3) |
| Почта владельца + фраза про Rockstar на видном месте (п. 2.3) | Реклама сторонних брендов и спонсоров (п. 3.1(7)) |
| Лаунчер бесплатный и необязательный | Продавать валюту, лутбоксы и т. п. (п. 3.1) — к лаунчеру не относится, но правило общее |

Совет: лаунчер — удобство, а не обязательное условие. В Discord и описании сервера оставьте и обычный способ: FiveM → поиск «COLDZ» или ссылка `cfx.re/join/...`.

## 1. Подготовка ПК (один раз)

На ПК Александра всё уже установлено (6.11.2026). На новом ПК:

1. **Node.js 22** — https://nodejs.org/ (LTS).
2. **Microsoft C++ Build Tools** — https://visualstudio.microsoft.com/visual-cpp-build-tools/ → отметить «Разработка классических приложений на C++» (~3–4 ГБ, нужны права администратора).
3. **Rust** — https://rustup.rs/ → `rustup-init.exe`, всё по умолчанию.
4. Открыть новое окно PowerShell в папке проекта и выполнить `npm install`.

## 2. Сборка — одна команда

```powershell
npm run build
```

Первый раз ~5–10 минут (качаются библиотеки), потом ~3 минуты. Готовый установщик:

```
release\<версия>\COLDZ-Launcher_<версия>_x64-setup.exe   ← его дают игрокам
release\<версия>\COLDZ-Launcher_<версия>_x64-setup.exe.sig
release\<версия>\latest.json                            ← для автообновления
```

Установщик ставит лаунчер без прав администратора (в профиль пользователя), создаёт ярлык и сам доустанавливает WebView2, если его нет (на Windows 10/11 он почти всегда уже есть).

Проверка без установки: `npm run dev` — откроется окно лаунчера. Тесты: `npm test`.

**Проверка кнопки «Играть»** (2 минуты):

1. Полностью закрыть FiveM.
2. Запустить установщик из `release\<версия>\`, открыть лаунчер с ярлыка.
3. Должно быть: «Сервер онлайн», игроки, пинг, «FiveM установлен — можно играть».
4. Нажать «Играть» → лаунчер сворачивается, открывается FiveM и сам подключается к адресу сервера (раздел 3).

Проверка вида без сборки: открыть `ui/index.html` через любой локальный веб-сервер из корня проекта (например `python -m http.server 8767`, затем `http://localhost:8767/ui/index.html`). Без Tauri страница работает на примерных данных; `?fivem=0` — «FiveM не установлен», `?address=0` — «адрес ещё не опубликован».

Если FiveM уже открыт и вы уже на этом сервере, повторное нажатие ничего не делает — FiveM просто игнорирует команду, игра не прерывается.

## 3. Адрес сервера — где менять

Адрес задаётся в **двух местах, главное — второе**:

1. **`news/news.json` → `"serverAddress"`** (на GitHub). Если тут не пусто — лаунчер берёт адрес отсюда. **Новая версия лаунчера не нужна**: поправили файл на GitHub → у игроков новый адрес при следующем запуске лаунчера (до ~5 минут кэша GitHub). Работает в лаунчерах начиная с версии 0.2.0.
2. **`launcher.config.json` → `"serverAddress"`** — запасной адрес, вшитый в лаунчер (если нет интернета до GitHub и лаунчер ещё ни разу не скачивал новости). После правки — пересобрать и выпустить версию (раздел 5).

Сейчас **оба пустые** — заглушка: лаунчер пишет «Скоро открытие», «Адрес сервера появится здесь перед открытием», кнопка «Играть» неактивна.

Формат адреса: `IP:порт` (`203.0.113.10:30120`), имя хоста (`play.example.ru:30120`, без порта — 30120) или код `cfx.re/join/abc123`. Что-то другое (пробелы, `?`, `/`, порт 0) лаунчер не примет и останется на запасном адресе. Адрес `127.0.0.1` — это ваш ПК, у игроков он работать не будет.

## 3а. Остальные настройки — файл `launcher.config.json`

```json
{
  "serverAddress": "",
  "maxPlayers": 48,
  "ownerEmail": "aaenlly@gmail.com",
  "newsUrl": "https://raw.githubusercontent.com/Poopseeque/coldz-launcher/main/news/news.json",
  "links": [
    { "icon": "vk", "label": "ВКонтакте", "url": "https://vk.ru/coldz_server" },
    { "icon": "facebook", "label": "Facebook (English)", "badge": "EN", "url": "https://www.facebook.com/..." },
    { "icon": "tiktok", "label": "TikTok", "url": "" }
  ]
}
```

- **`serverAddress`** — запасной адрес (раздел 3).
- **`links`** — кнопки соцсетей внизу окна, в том же порядке. Ссылок можно сколько угодно. `icon` — значок: `vk`, `facebook`, `youtube`, `tiktok`, `discord`, `telegram`, `instagram`, `x`; `label` — подсказка при наведении; `badge` — маленькая подпись на значке (необязательно, например `EN`/`PT`). Только ссылки `https://`.
- Ссылка с пустым `url` (`""`) просто не показывается — так сейчас с Telegram. Как появится канал — впишите `https://t.me/...`.
- После любой правки этого файла — пересобрать и выпустить новую версию: настройки вшиваются в лаунчер.

## 4. Новости, правила, адрес — файл `news/news.json`

Лаунчер берёт из `news/news.json` этого репозитория на GitHub (адрес в `newsUrl`):

- `"serverAddress"` — адрес сервера (раздел 3);
- `"rules"` — вкладка «Правила». Сейчас там те же 6 правил на 4 языках, что на экране загрузки сервера (`winter-server/resources/[z]/z_loadscreen/locales/*.json` → `rules`). Поменяли правила на сервере — поправьте и здесь;
- `"items"` — новости.

Чтобы опубликовать новость, ничего пересобирать не нужно:

1. Открыть на GitHub файл `news/news.json` → карандаш «Edit».
2. Добавить запись в `items` (пример ниже) → «Commit changes».
3. Игроки увидят новость при следующем запуске лаунчера (GitHub может отдавать старую версию до ~5 минут).

```json
{
  "id": "wipe-2026-12-01",
  "date": "2026-12-01",
  "pinned": false,
  "title": { "ru": "Вайп 1 декабря", "en": "Wipe on December 1", "es": "Wipe el 1 de diciembre", "pt-BR": "Wipe em 1º de dezembro" },
  "body":  { "ru": "Текст новости…", "en": "News text…" },
  "url": "https://discord.gg/FUMCMhdNH7",
  "image": "https://…/картинка.jpg"
}
```

- Языки можно заполнять не все: если перевода нет — покажется русский текст.
- `pinned: true` — новость всегда сверху с пометкой «Важно».
- `url` (кнопка «Подробнее») и `image` — необязательные, только `https://`.
- Если запятая или кавычка будет пропущена, лаунчер покажет прошлые новости. Проверить файл можно на https://jsonlint.com/.

Почему так, а не канал Telegram: JSON на GitHub бесплатный, стабильный и даёт тексты на 4 языках. Читать канал Telegram можно только разбором его веб-страницы — это ломается при любой смене вёрстки Telegram и не работает там, где Telegram заблокирован.

## 4а. Ник на сервере (с версии 0.3.0)

Над кнопкой «Играть» — поле **«Ник»**. Что поставил игрок, то и будет его ником на сервере везде: список игроков (Tab), F2, ник над головой, чат, таблица лидеров, подпись у трупа, клан, GPS. Менять можно когда угодно, одинаковые ники у разных игроков можно (как в DayZ). Лаунчер помнит ник. **Пустое поле — ник из FiveM.**

Правила (те же, что на сервере): русские и английские буквы, цифры, пробел, `-` и `_`, хотя бы одна буква или цифра, до 20 русских или 40 английских букв (40 байт). Нельзя слова команды в любом написании — админ/admin, модер/moderator, создатель/creator, owner, владелец, поддержка/support, helper, staff, developer, разработчик; весь ник «Server», «Сервер», «System», «Console», «COLDZ» (включая «Аdmin» с русской «А», «Adm1n», «A d m i n»). Метку роли (Создатель, Администратор, Модератор) рисует только сервер — ником её не подделать. Список слов — на сервере: `winter-server/resources/[z]/z_menu/config.lua` → `nick`.

Что видит игрок после «Играть»:

- ник не по правилам — красная подсказка под полем сразу при вводе, «Играть» неактивна;
- сервер отказал (слова команды, слишком часто) — причина под полем, FiveM **не** запускается;
- всё хорошо — «Ник „…“ будет на сервере при входе», запускается FiveM; в игре после появления — «Ваш ник на сервере: …»;
- сервер не ответил (нет связи, старый сервер без поддержки ника) — «ник не поменяли», FiveM запускается как обычно.

Как устроено (почему не через сам FiveM): ник самого FiveM нельзя надёжно выставить снаружи — поле «Ник» в меню FiveM хранится во встроенном браузере FiveM и всегда главнее настройки `cl_nickname` в `%APPDATA%\CitizenFX\fivem.cfg`; параметры ссылки `fivem://connect/…?…` до сервера не доходят (FiveM читает из них только `streamerMode`); запускать FiveM.exe с параметрами FiveM не даёт. Поэтому лаунчер сообщает ник **нашему серверу** перед запуском FiveM:

```
POST http://<адрес сервера>/z_menu/nick      {"nick": "Снег", "launcher": "<случайный номер этой установки>"}
→ {"ok": true, "nick": "Снег"}   или   {"ok": false, "reason": "reserved" | "chars" | "long" | "often" | "bad"}
```

Это тот же адрес и порт, что `/dynamic.json` (ресурс `z_menu`, файл `server/nick.lua`). Сервер помнит ник 10 минут по IP игрока; игрок с этого IP подключился — ник его; при «Играть» в главном меню сервера персонаж переименовывается. Перезашёл без лаунчера (вылет, «Переподключиться» в FiveM) — ник тот же; сменил ник в самом FiveM — ник из FiveM. Если с одного IP (одна квартира) почти одновременно пришли ники из двух лаунчеров — сервер не гадает, ник не меняет и пишет об этом в игре. Лаунчер хранит ник и случайный номер установки в `%APPDATA%\com.coldz.launcher\settings.json`.

Если игрок уже в игре, «Играть» FiveM не прерывает (раздел 2) — новый ник будет при следующем входе.

Проверка вида без сборки (раздел 2): `?nick=down` — сервер «не отвечает»; ник со словом admin/админ — «нельзя», со словом often — «слишком часто».

## 5. Выпуск новой версии (автообновление)

Один раз: на GitHub (аккаунт `Poopseeque`) создать **публичный** репозиторий `coldz-launcher` и отправить туда этот проект (`git remote add origin https://github.com/Poopseeque/coldz-launcher.git`, `git push -u origin main`). Публичный — потому что игроки скачивают из него установщик, обновления и новости. Секретов в проекте нет: ключи лежат вне папки.

Каждый выпуск:

```powershell
npm run set-version -- 0.1.1
npm run release -- -Notes "Новый адрес сервера"
git add package.json src-tauri/Cargo.toml src-tauri/Cargo.lock src-tauri/tauri.conf.json
git commit -m "Версия 0.1.1"; git push
```

`npm run release` подписывает обновление ключом из `C:\Users\Aaenl\.coldz-launcher-keys\updater.key` (сам находит его; без ключа выпуск остановится с ошибкой) и кладёт `.sig` и `latest.json` рядом с установщиком.

Проверка подписи открытым ключом (секретный не нужен): `python scripts/verify-update.py 0.1.1` — файлы `release\0.1.1\`; после публикации `python scripts/verify-update.py --url` — то, что получают игроки. Порядок выпуска и грабли для Claude — `docs/ПРАВИЛА.md`.

Затем на GitHub: **Releases → Draft a new release** → тег `v0.1.1` → прикрепить три файла из `release\0.1.1\` (`…setup.exe`, `…setup.exe.sig`, `latest.json`) → **Publish release**.

Все установленные лаунчеры при следующем запуске покажут «Вышла новая версия лаунчера 0.1.1 — Обновить». Ссылка для скачивания на сайт/в Discord всегда одна и та же:
`https://github.com/Poopseeque/coldz-launcher/releases/latest`

### Ключ обновлений — важно

Обновления подписаны своим ключом (бесплатно, не путать с подписью Windows). Ключ лежит **вне репозитория**:
`C:\Users\Aaenl\.coldz-launcher-keys\updater.key` (+ `updater.key.pub`).

- Сохраните копию папки `.coldz-launcher-keys` на флешку / в облако. **Если ключ потерять, уже установленные лаунчеры больше не смогут обновиться** — придётся просить всех переустановить.
- Никому не отправлять и не класть в git (в `.gitignore` уже запрещено).
- Публичная половина ключа вшита в `src-tauri/tauri.conf.json` → `plugins.updater.pubkey`.

## 6. Подпись установщика (сертификат Windows)

Сейчас установщик **не подписан** сертификатом Windows: при первом запуске Windows SmartScreen покажет «Неизвестный издатель» → игроку нужно нажать «Подробнее» → «Выполнить в любом случае». Обновления при этом защищены своим ключом (раздел 5).

Чтобы убрать предупреждение, нужен платный сертификат подписи кода (цены на ноябрь 2026, примерные — проверить перед покупкой):

- **Azure Artifact Signing** (бывший Trusted Signing, Microsoft) — **$9,99 в месяц** (~$120 в год), до 5000 подписей. Частным лицам выдают только в США и Канаде (организациям — ещё ЕС и Великобритания); нужна проверка личности по документам США. **Рекомендуемый вариант**, если владелец живёт в США. Подпись — через `COLDZ_SIGN_COMMAND`.
- **SSL.com** (сертификат на частное лицо, IV/OV) — от ~$65–130 в год у реселлеров, плюс токен или облачная подпись eSigner.
- **Sectigo / Comodo OV** — ~$220 в год; **DigiCert OV** — ~$400–440 в год.
- **SignPath Foundation** — бесплатно для проектов с открытым кодом (репозиторий уже публичный), но нужна открытая лицензия и одобрение заявки.

С 1 марта 2026 сертификаты выдают максимум на 460 дней — продлевать каждый год.

Даже с сертификатом SmartScreen какое-то время предупреждает, пока у файла не наберётся «репутация» (число скачиваний).

Когда сертификат будет — задать одну переменную окружения и собрать как обычно, скрипт подпишет и лаунчер, и установщик:

```powershell
$env:COLDZ_SIGN_THUMBPRINT = "<отпечаток сертификата>"   # сертификат на токене / в хранилище Windows
# или: $env:COLDZ_SIGN_PFX = "C:\путь\cert.pfx"; $env:COLDZ_SIGN_PFX_PASSWORD = "..."
# или: $env:COLDZ_SIGN_COMMAND = "<своя команда подписи> {file}"
npm run release -- -Notes "..."
```

## 7. Ошибка FiveM «Failed to initialize LinkProtocolIPC» (с версии 0.3.1)

**Что это.** Окно FiveM «Failed to initialize LinkProtocolIPC, master is already initialized» (кнопки «Save information» / «Закрыть») значит: FiveM запустили второй раз, пока в памяти Windows ещё жив прошлый FiveM — завис в фоне без окна, ещё закрывается или висит с окном ошибки. Так устроен FiveM (исходники citizenfx/fivem, `LinkProtocolIPC.cpp`, `ConnectToNative.cpp`): каждый новый FiveM ищет уже работающий и передаёт ему ссылку `fivem://connect`; новая игра стартует, только если старой нет, а если в памяти осталась «живая» старая — эта ошибка. Если нажать «Играть» ещё раз, пока FiveM только запускается, бывает похожая ошибка «… no master process».

**Что делает лаунчер с 0.3.1** перед «Играть» (`src-tauri/src/running.rs`):

- FiveM не запущен — запускает, как раньше;
- FiveM открыт (окно игры или меню FiveM есть) — передаёт ему ссылку, FiveM сам подключится к COLDZ («FiveM уже открыт: подключаем…»);
- лаунчер сам запустил FiveM меньше 2,5 минуты назад, а окна игры ещё нет — второй раз не запускает: «FiveM ещё запускается, подождите»;
- процессы FiveM есть, а окна игры нет (завис, обновляется, окно ошибки) — не запускает и показывает кнопку **«Закрыть FiveM»**: закрывает все процессы `FiveM*`. Если FiveM запущен от администратора, лаунчер закрыть его не сможет и скажет закрыть через Диспетчер задач.

**Что делать игроку сейчас** (любая версия лаунчера):

1. Нажать «Закрыть» в окне ошибки.
2. Открыть Диспетчер задач: `Ctrl+Shift+Esc` → вкладка «Процессы» → снять задачу у **всех** строк, которые начинаются с «FiveM» (`FiveM`, `FiveM_b3258_GTAProcess`, `FiveM_ChromeBrowser`, `FiveM_DumpServer`, `FiveM_ROSLauncher`, `FiveM_ROSService` и т. п.). Строк может не быть на первой вкладке — тогда на вкладке «Подробности».
3. Нажать «Играть» в лаунчере **один раз** и подождать: FiveM открывается до минуты, при первом входе дольше. Повторно «Играть» не нажимать.
4. Не помогло — перезагрузить ПК (это тоже закроет всё, что осталось от FiveM).

## Как устроено

```
launcher.config.json      адрес сервера, почта, ссылки, адрес новостей
news/news.json            адрес сервера, правила, новости (на GitHub — живые, в лаунчере — запасная копия)
ui/                       окно лаунчера: index.html, style.css, app.js, i18n.js (тексты на 4 языках), icons.js (значки соцсетей, Simple Icons, CC0)
branding/                 исходник иконки, старый логотип-картинка (в окне COLDZ теперь рисуется шрифтом, как на экране загрузки)
src-tauri/src/lib.rs      поиск FiveM, запуск, статус сервера, адрес из news.json, новости, обновление
src-tauri/src/nick.rs     ник: правила, settings.json, ответ сервера (раздел 4а)
src-tauri/src/running.rs  FiveM уже запущен? процессы, окно игры, «Закрыть FiveM» (раздел 7)
src-tauri/tauri.conf.json окно, установщик, адрес обновлений и публичный ключ
scripts/build.ps1         сборка одной командой (npm run build / npm run release)
scripts/sign.ps1          подпись сертификатом Windows (когда появится)
scripts/set-version.ps1   смена версии в трёх файлах
scripts/verify-update.py  проверка подписи обновления открытым ключом (раздел 5)
docs/ПРАВИЛА.md           правила и грабли для следующего Claude
LICENSE-INSTALLER.txt     первая страница установщика (почта + фраза про Rockstar)
```

- **Поиск FiveM**: реестр Windows (`FiveM.ProtocolHandler`, `fivem`), затем `%LOCALAPPDATA%\FiveM\FiveM.exe`.
- **«Играть»**: сначала ник серверу (`POST /z_menu/nick`, раздел 4а; отказ — FiveM не запускается), затем проверка, не запущен ли FiveM (раздел 7), затем ссылка `fivem://connect/<адрес>` через проводник Windows (FiveM запускается только из оболочки), запасной путь — `FiveM.exe "fivem://connect/<адрес>"`, потом открыть ссылку через Windows. После запуска окно лаунчера сворачивается.
- **Адрес**: `serverAddress` из `news.json` (скачанного, сохранённого или вшитого), если он не пустой и правильный; иначе `serverAddress` из `launcher.config.json`; иначе «адрес не задан».
- **Статус**: `http://<адрес>/dynamic.json` (игроки и лимит), если его нет — `/players.json` + `/info.json`; таймаут 4 с. Пинг — время TCP-подключения к порту сервера (лучшее из 3). Для адреса `cfx.re/join/...` статус берётся из списка серверов FiveM.
- Иконки собираются из `branding/icon-source.png`: `npm run icons`.
